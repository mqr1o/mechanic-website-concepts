# Auto shop website concepts

Website design and development by **Aansh Bali**.
Portfolio and résumé: https://aanshbali.com/

Independent, unofficial website concepts for local auto repair shops. They have not been commissioned or endorsed by the businesses.

Each concept includes a responsive layout, service sections, image gallery, attributed review excerpt, business contact links, a Google map, and a website proposal with a Zoom-call invitation.

The proposal offers a one-time website build, with no monthly or annual service charges from Aansh. Domain registration and renewal are separate registrar charges. Paid hosting or additional services require separate agreement.

## Preview paths

- `preferred/` — Preferred Auto Repair, Santa Clara
- `quik-smog/` — Quik Smog Hayward
- `youngs/` — Young's Automotive, Napa

## Run locally

Serve this folder with a static web server, for example `python3 -m http.server 8000`.
